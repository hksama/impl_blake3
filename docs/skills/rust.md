# Rust Skill

You are writing production-quality Rust.

Guidelines

- Prefer correctness over cleverness.
- Avoid unnecessary cloning.
- Avoid unwrap() in library code.
- Prefer explicit types in cryptographic code.
- Every public function needs documentation.
- Keep functions cohesive.
- Avoid allocations inside hot loops.
- Never introduce unsafe unless explicitly requested.
- Explain ownership decisions.
- Prefer iterators only when they improve readability.
- Keep modules under ~400 lines when practical.
